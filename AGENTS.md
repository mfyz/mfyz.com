# Blog drafting

When drafting or revising a post with the user, offer inline review in the
Astro preview by default. Use the
[draft-review skill](.agents/skills/draft-review/SKILL.md) to open a round
on the current post. Open the review URL when requested, or share the full
clickable URL so the user can comment and suggest deletions in the preview.
Keep `?preview=1` for hidden drafts and preserve the review token in the URL.
Use a reachable dev-server address for the user's device.

Keep the chat open to receive submitted feedback. Apply the edits here and
reuse the same review URL for the next round. When the user asks for a plain
preview or wants to give feedback in chat, follow their preference.
